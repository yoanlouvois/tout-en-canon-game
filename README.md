## Le jeu

Une légende raconte qu'un merveilleux trésor est caché au cœur de la pyramide de Tout en Canon. Pour ouvrir la porte du trésor, il faut d'abord retrouver le **pied-de-biche**, puis l'utiliser par glisser-déposer.

Mais la pyramide est maudite : chaque salle possède quatre portes, et une porte ne s'ouvre que si la porte correspondante de la salle voisine est ouverte. Grâce à vos pouvoirs divins, vous pouvez afficher la carte de la pyramide et **échanger les salles de place** pour vous frayer un chemin.

Attention, des monstres rôdent dans certaines salles. Tirez-leur dessus et utilisez vos potions pour survivre. Un conseil : notez les salles visitées, sous peine de vous perdre à jamais…

## Commandes

| Touche | Action |
|---|---|
| `Z` `Q` `S` `D` | Se déplacer entre les salles |
| `R` | Afficher la carte de la pyramide |
| `Z` `Q` `S` `D` (sur la carte) | Échanger les salles |
| Clic gauche | Tirer sur les monstres |
| `A` | Utiliser une potion |
| Glisser-déposer | Utiliser le pied-de-biche sur la porte du trésor |

## Technologies

`Java 8` `JavaFX`
